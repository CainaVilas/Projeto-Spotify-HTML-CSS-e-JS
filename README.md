# 🎵 DevCainã Music

Interface web inspirada em plataformas de streaming musical, desenvolvida com **HTML, CSS e JavaScript**. O projeto simula uma página de música com navegação lateral, campo de busca e exibição dinâmica de artistas e álbuns.

## ✨ Funcionalidades

* 🎧 Interface inspirada no Spotify
* 🔎 Campo de busca
* 🎤 Seção de artistas populares
* 💿 Seção de álbuns
* 🖼️ Cards gerados dinamicamente com JavaScript
* 📱 Layout responsivo com CSS Grid
* 🎨 Efeitos de hover e estilização personalizada
* ⚡ Carregamento das informações após o carregamento da página
* 🖼️ Carregamento otimizado das imagens com `lazy loading`

## 🛠️ Tecnologias

* **HTML5** — estrutura da aplicação
* **CSS3** — layout, responsividade e estilização
* **JavaScript** — manipulação do DOM e renderização dinâmica
* **Font Awesome** — ícones da interface

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/CainaVilas/SEU-REPOSITORIO.git
```

2. Acesse a pasta:

```bash
cd SEU-REPOSITORIO
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão atual.

## 🎯 Objetivo

Projeto desenvolvido para praticar **desenvolvimento front-end**, com foco em estruturação de páginas, estilização com CSS, manipulação do DOM e criação de componentes visuais dinamicamente com JavaScript.
